# DOXA Sanctuary — Website

Official website for **DOXA Sanctuary** — *"Expressing His Glory"* — a church family at 865 Morris Park Ave, Bronx, NY, with Sunday service at 10:00 AM.

🔗 **Live site:** [doxatopchurch.org](https://doxatopchurch.org/)

---

## Overview

A static, multi-page website built with HTML, CSS, and vanilla JavaScript, deployed via GitHub Pages with a custom domain (see `CNAME`).

## Pages

- `index.html` — Home
- `about.html` — About the church
- `leadership.html` — Leadership team
- `service-times.html` — Service times & location
- `ministries.html` — Ministries overview
  - `mens-ministry.html`, `womens-ministry.html`, `youth-ministry.html`, `childrens-ministry.html`, `small-groups.html`
- `sermons.html` — Sermon archive (YouTube embeds)
- `events.html` / `calendar.html` — Events & calendar
- `gallery.html` — Photo gallery
- `baptism.html` — Baptism info
- `bible-reading-plan.html` — Bible reading plan
- `give.html` — Online giving
- `new-here.html` / `contact.html` — Visitor info & contact
- `volunteer.html`, `register-child.html`, `join-*-ministry.html` — Sign-up forms
- `thank-you.html` — Form submission confirmation

## Structure

```
doxa-sanctuary/
├── index.html
├── *.html          # individual pages
├── css/style.css   # site styles
├── js/main.js      # site behaviour
├── js/youtube.js   # sermon video embeds
├── assets/         # images & PDFs (e.g. bible reading plan)
└── CNAME           # custom domain config
```

## Tech Stack

HTML5 · CSS3 · JavaScript · GitHub Pages
